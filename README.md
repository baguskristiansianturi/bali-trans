# BDM Trans — Homepage Reset

The repository is being restarted around a single, colorful Bali travel homepage. The current concept is a static prototype, not a live booking platform.

## Visual direction
Coral, tropical aqua, sunflower yellow, lilac and deep green; expressive display typography; destination photography; a compact discovery flow inspired by travel marketplaces such as Klook without copying their brand or interface wholesale.

## Current scope
- `index.html`: standalone responsive homepage with inline styling and client-side inspiration-card search.
- The previous secondary pages, stylesheets and JavaScript files have been removed from the working branches for a clean reset. Git history is preserved.

## Not production-ready
- Experience cards are editorial inspiration, not verified inventory or bookable offers.
- Search is a small client-side filter, not a live product search.
- Configure the actual business WhatsApp number before launch.
- Remote Unsplash images need review for final use.
- Preview remains noindex until launch policy is reviewed.
