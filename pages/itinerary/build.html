Plan your day

Start with one priority. Add the rest around it.

A good itinerary is realistic, not packed. Start with the one thing you most want to do, check its timing, then add nearby places around it. Leave room for traffic, meals, queues and rest. If an activity has a fixed start time, plan the journey around that first.
